# Support

- **Using the app** — the [README](README.md) covers installation, profiles, [repository-scoped identity](README.md#repository-scoped-identity), and a [Troubleshooting](README.md#troubleshooting) section for SmartScreen, GitHub device-code errors, and GitLab OAuth failures; anything it doesn't, ask in a [question issue](https://github.com/khasky/git-account-manager/issues/new?template=question.md).
- **Something broken** — open a [bug report](https://github.com/khasky/git-account-manager/issues/new?template=bug_report.md) with your OS, app version, and the failing `git` / `ssh` output.
- **Want a feature** — check the [roadmap](README.md#roadmap) first, then open a [feature request](https://github.com/khasky/git-account-manager/issues/new?template=feature_request.md).
- **Security problems** — never in a public issue: [open a private security advisory](https://github.com/khasky/git-account-manager/security/advisories/new). See [SECURITY.md](SECURITY.md).

Contributing code instead? Start with [CONTRIBUTING.md](CONTRIBUTING.md).
